简体中文 · Stompal Gastric Cancer Workbench

小胃宝（Stompal）是面向胃癌患者及照护者的 DSH Desktop 本机优先工作台。它帮助用户整理 HER2 / PD-L1 CPS / MSI / CLDN18.2 四项关键标志物、记录胃切除方式与进食营养变化、按治疗线回顾方案与体重趋势。医疗内容只用于资料整理和就诊沟通，不替代医生诊断或治疗意见。

### 定义

胃癌是起源于胃黏膜上皮的恶性肿瘤，病理类型以腺癌为主。「长在胃的哪一段」和「长到哪一期」是两件事：前者写部位，后者写 TNM，本台分开记录、不互相推导。

部位按上 1/3、中 1/3、下 1/3 与贲门记录，用哪一段的写法以胃镜与病理报告原文为准。病理类型照报告原文抄（腺癌及其亚型等），本台不改写、不合并、不换算。分期为 TNM 体系，具体采用哪一版以病理与影像报告上标注的为准；本台不自行分期、不把部位推成分期。四个标志物 HER2 / PD-L1 CPS / MSI / CLDN18.2 各自独立记录为「检测了 / 未检测 / 待出」三态，未检测不补成阴性。腹膜转移与腹腔治疗在本台单列，不与肝转移、淋巴结转移合并成一条。

### 目前治疗全景概要

下面按期别与线序列出指南里出现过的手段类别。这是「世界上大致有哪些办法」的地图，不是给你排的先后顺序，也不含任何剂量、疗程与适用条件。

- **局限期（病变可以切除时）**：内镜切除（EMR / ESD）被列为早期病变的处理方式之一；手术包括远端胃切除、近端胃切除、全胃切除与淋巴结清扫；围手术期化疗按术前与术后两个阶段分开表述；术后辅助化疗在术后病理存在特定风险因素时被列出；放化疗在部分情形下被列为可讨论选项。
- **晚期 / 转移后**：以氟尿嘧啶类与铂类为基础的全身化疗；HER2 靶向治疗（针对 HER2 阳性情形）；免疫检查点抑制剂（按 PD-L1 CPS、MSI/dMMR 等检测结果分层列出）；CLDN18.2 靶向治疗（针对 CLDN18.2 阳性情形）；腹膜转移情形下的腹腔治疗；以及作为正式选项的临床研究。
- **贯穿全程**：切除方式不同，进食调整与 B12 / 铁 / 钙等补充的医嘱也不同，本台只记医嘱原文与起止；胃镜与影像的复查节点按指南与医生安排执行，本台只把「约在哪天、做了没有」整理成时间线。

> 以上是文献与指南里列出的手段，按病期与线序排列，不代表任何一项适合你。选哪一个，这一句需要问你的医生。

## 产品范围（一期规划）

- 标志物档案（专属主线）：HER2 / PD-L1 CPS / MSI / CLDN18.2 各自独立状态（检测/未检测/待出），未检测不补阴性；CA19-9 缺数值不等于正常（Lewis 阴性不表达人群，显式标注位）。
- 进食与营养（专属模块，权重最高之一）：切除方式档案（全胃/近端/远端/ESD）、进食记录（少食多餐、倾倒症状）、补充剂医嘱留痕（B12/铁/钙，只记不推荐剂量）。
- 治疗历程：围手术期方案区分术前/术后阶段；腹膜转移与腹腔治疗记录。
- 病情一图秀：以体重为主指标，治疗节点分离。
- 复诊准备 / 临床研究 / 设置：与家族通用骨架一致。

## 数据与能力边界

- 患者数据必须存入用户明确选择的资料目录；导入文件在本机处理，识别字段先作为候选内容展示，用户核对后才写入病情记录。
- 2026 临床试验资料包按家族统一方法学采集（见 docs/CLINICAL-DATA-2026.md， gastric 资料包已采集：236 条）；登记不证明有效、安全或开放入组。
- 临床试验搜索结果是查找线索，不代表符合入组条件；试验状态和入排标准应向研究中心核实。
- 工作台不提供诊断、分期判读、疗效评价或处置建议；用户看法与担心按"一条信息"记录，标注"不是医生结论"。
- 原型中全部数据为虚构演示数据，不是真实病例。
