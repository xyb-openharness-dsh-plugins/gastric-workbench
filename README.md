简体中文 · Stompal Gastric Cancer Workbench

小胃宝（Stompal）是面向胃癌患者及照护者的 DSH Desktop 本机优先工作台。它帮助用户整理 HER2 / PD-L1 CPS / MSI / CLDN18.2 四项关键标志物、记录胃切除方式与进食营养变化、按治疗线回顾方案与体重趋势。医疗内容只用于资料整理和就诊沟通，不替代医生诊断或治疗意见。

## 当前状态（v0.1.0，2026-10-21，如实）

- **开发版已落地**：SPEC v0.1（`docs/SPEC.md`）、交互原型 v0.2（`prototypes/v0.2/`，10 个一级页）、2026 临床试验资料包 236 条（`docs/CLINICAL-DATA-2026.md`）、schema 冻结（`schema/freeze-contract.md`）、开发版 `public/ + dsh/`（`npm run check` 全绿，21 项测试含原型↔开发版逐字段 parity）。

## 产品范围（一期规划）

- 标志物档案（专属主线）：HER2 / PD-L1 CPS / MSI / CLDN18.2 各自独立状态（检测/未检测/待出），未检测不补阴性；CA19-9 缺数值不等于正常（Lewis 阴性不表达人群，显式标注位）。
- 进食与营养（专属模块，权重最高之一）：切除方式档案（全胃/近端/远端/ESD）、进食记录（少食多餐、倾倒症状）、补充剂医嘱留痕（B12/铁/钙，只记不推荐剂量）。
- 治疗历程：围手术期方案区分术前/术后阶段；腹膜转移与腹腔治疗记录。
- 病情一图秀：以体重为主指标，治疗节点分离。
- 复诊准备 / 临床研究 / 设置：与家族通用骨架一致。

## 数据与能力边界

- 患者数据必须存入用户明确选择的资料目录；导入文件在本机处理，识别字段先作为候选内容展示，用户核对后才写入病情记录。
- 2026 临床试验资料包按家族统一方法学采集（见 docs/CLINICAL-DATA-2026.md， gastric 资料包已采集：236 条）；登记不证明有效、安全或开放入组。
- 临床试验搜索结果是查找线索，不代表符合入组条件；试验状态和入排标准应向研究中心核实。
- 工作台不提供诊断、分期判读、疗效评价或处置建议；用户看法与担心按"一条信息"记录，标注"不是医生结论"。
- 原型中全部数据为虚构演示数据，不是真实病例。
