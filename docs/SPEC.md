# SPEC · 小胃宝 Stompal 胃部瘤工作台 v0.1

日期：2026-10-18。状态：**草案，等待 G1/G2 审**。样板链路（结直肠癌）确认后复用其工程骨架；本文先定范围、立场、验收。

## 0. 三道闸口

同结直肠癌 SPEC §0（G1 待签 / G2 本轮未审 / G3 未开始）。胃癌本轮只交付 SPEC 草案；HTML demo 在样板确认后批量产出。

## 1. 目标与非目标

**目标**：让胃癌患者（及照护者）回答五个问题：

1. 我的分期和四个关键标志物（HER2 / PD-L1 CPS / MSI / CLDN18.2）各是什么？（**标志物**）
2. 我切了多少胃？现在怎么吃、缺什么补什么？（**进食与营养**）
3. 现在用什么方案、第几程、改过什么？（**治疗**）
4. 体重/白蛋白/B12 等营养线趋势如何？（**营养趋势**）
5. 下次门诊带什么问什么？（**就诊准备**）

**非目标**：不做诊断、不做营养处方、不推荐补剂品牌、不做 Hp 根除建议、不做病友社区。

## 2. 产品立场

继承家族 9 条立场（见结直肠癌 SPEC §2），胃癌补充：

10. **营养数值只呈现不处方**：B12/铁/钙/D 的补充由医嘱驱动；工作台记录"医生开了什么、吃到什么时候"，不推荐剂量。
11. **标志物阴性不写"没药可用"**：HER2 阴性等只记原值；可讨论问题清单交给用户，不给"还有没有希望"类表述。

## 3. 范围（一期）

| 模块 | 内容 | 差异点 |
| --- | --- | --- |
| 看板 | 定调条 →「现在可以做」→ **营养状态卡（体重+进食）** → 标志物摘要卡 → 接下来/最近变化 | 营养卡升为看板第二卡 |
| 我的分型 | 分期（TNM）、部位（上/中/下 1/3、贲门）、**标志物档案（HER2/PD-L1 CPS/MSI/CLDN18.2，各自"检测了/未检测"）**、Hp 病史、家族史 | 标志物矩阵是本癌种核心 |
| 治疗历程 | 治疗线 / 围手术期方案（术前/术后阶段标注）/ 周期与用药 / **腹膜转移与腹腔治疗记录** | 围手术期两阶段结构 |
| **进食与营养（专属一级模块，权重最高之一）** | 切除方式档案（全胃/近端/远端/ESD）、进食记录（少食多餐/倾倒症状）、补充剂记录（B12/铁/钙，医嘱驱动）、营养指标（白蛋白/前白蛋白） | 胃癌两条主线之一 |

| 心理支持 | 当下感受 / 身体形象与进食社交 / 生育与家庭 | 骨架 + 专属子页 |
| 复诊准备 | 复诊节奏 / **胃镜随访节点** / 就诊准备 | 胃镜替代肠镜位 |
| 临床研究 | 2026 线索 / 已收藏 / 入组问题 | 骨架 |
| 设置 | 同骨架 | 骨架 |

### 明确不做

补剂剂量推荐、Hp 根除建议、倾倒综合征自疗方案、"残胃癌风险"概率表述、病友匹配。

## 4. 信息架构（10 个一级页）

```
看板
我的分型 ── 分期与部位 / 标志物档案 / Hp与家族史 / 会诊
治疗历程 ── 围手术期方案 / 周期与用药 / 腹膜与腹腔治疗
进食与营养 ── 切除方式 / 进食记录 / 补充剂与指标 / 倾倒记录
检查与指标 ── 肿瘤标志物 / 血象 / 影像与胃镜
病情一图秀（体重默认）
心理支持
复诊准备 ── 复诊节奏 / 胃镜随访 / 就诊准备
临床研究
```

差异自查：结直肠癌的「肠道功能与造口」位由「进食与营养」顶替；营养支持不再单列（并入进食与营养）；一图秀默认指标是体重不是 CEA。

## 5. 特有场景

| # | 场景 | 给什么 | 不给什么 |
| --- | --- | --- | --- |
| G1 | 四标志物报告看不懂 | 逐项状态化矩阵+检测日期+来源 | 不说"能用什么靶向药" |
| G2 | 全胃切除后怎么吃 | 进食记录+补充剂医嘱留痕+倾倒症状记录 | 不给食谱处方、不推补剂 |
| G3 | 术前/术后方案切换沟通 | 围手术期两阶段对照 | 不评价方案优劣 |
| G4 | 腹膜转移 / 腹腔灌注沟通 | 治疗记录+影像对照 | 不判断疗效 |
| G5 | CA19-9 一直"没数值" | Lewis 阴性标注位（医生结论原文） | 不把缺失当正常 |
| G6 | 复发找试验 | 2026 线索+入组问题（CLDN18.2 等作检索词） | 不排序不预测 |

## 6. 验收（A 条目要点）

| # | 条目 |
| --- | --- |
| A1 | 标志物矩阵四项各自独立状态（检测/未检测/待出），未检测不补阴性 |
| A2 | CA19-9 页出现"本标志物在部分人群中不表达，缺数值不等于正常"占位说明（医生结论原文位） |
| A3 | 切除方式档案四选一+手术日期+机构 |
| A4 | 进食记录支持餐次+症状标记（倾倒/反流/腹胀），无处理建议 |
| A5 | 补充剂记录只显示医嘱原文与起止，无剂量推荐 |
| A6 | 体重为主指标的一图秀：kg 序列+治疗节点分离 |
| A7 | 围手术期方案区分"术前/术后"阶段标签 |
| A8-A14 | 同家族通用条目（viewpoint 标注/导出两区/文案红线/设置防护/横向溢出/线索免责） |
| A15 | 无「营养支持」一级页（防双入口回归） |

## 7. 风险

进食记录负担高 → 默认只记"异常餐"；营养模块变成卖货入口 → 补充剂只记医嘱。

## 8. 术语

CPS：PD-L1 联合阳性评分；CLDN18.2：Claudin 18.2；倾倒综合征：胃切除后进食后头晕心悸腹泻一组表现；Lewis 阴性：不分泌 CA19-9 相关抗原的人群状态。
