# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：胃癌（腺癌为主）患者及照护者；胃部瘤语境以小胃宝既有品牌为准

场景：刚确诊面对HER2/PD-L1 CPS/MSI/CLDN18.2多个标志物报告；全胃或部分胃切除后倾倒综合征与长期营养补充管理；腹膜转移患者的腹腔治疗路径沟通；复诊与营养指标随访

核心流程：
1. 选择本机资料目录并导入病理/影像/检验报告
2. 核对候选信息，建立标志物与分期档案
3. 记录切除方式、进食与营养补充情况
4. 按治疗线整理方案、周期与营养趋势
5. 生成复诊准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：标志物档案、胃切除方式与营养记录、治疗历程、体重与营养趋势、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first

## 用户新增确认（2026-10-18）

- 与结直肠癌、食管癌、宫颈癌三个新癌种同批启动，「样板先行+批量」：胃癌本轮只到 SPEC 草案，样板链路由结直肠癌先行打通，确认后复用骨架批量产出。
- 差异化力度定为「中等：共享骨架+专属模块」；不得把同一套分类换名字复用（用户原话要点见结直肠癌 BRIEF 引文）。
- 胃癌专属主线定为「四标志物（HER2/PD-L1 CPS/MSI/CLDN18.2）+ 胃切除方式与进食营养」；营养模块权重高于通用（少食多餐、倾倒综合征、B12/铁/钙）。
- 品牌：沿用既有 Stompal 小胃宝 Logo（橙色）；无文字标识过渡问题。
- 参照物同结直肠癌条目。
