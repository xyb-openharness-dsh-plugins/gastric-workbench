## 1 定义（`definition`）

胃癌是起源于胃黏膜上皮的恶性肿瘤，病理类型以腺癌为主。「长在胃的哪一段」和「长到哪一期」是两件事：前者写部位，后者写 TNM，本台分开记录、不互相推导。

- 部位按上 1/3、中 1/3、下 1/3 与贲门记录，写法以胃镜与病理报告原文为准。
- 病理类型照报告原文抄，不改写、不合并、不换算。
- 分期为 TNM 体系，采用哪一版以报告标注为准；本台不自行分期。
- HER2 / PD-L1 CPS / MSI / CLDN18.2 四个标志物各自独立记录为「检测了 / 未检测 / 待出」，未检测不补成阴性。
- 腹膜转移与腹腔治疗单列，不与肝转移、淋巴结转移合并。

- 不写「预后差 / 恶性程度高 / 发展快」这类判读。
- 亚型名字一律用报告原文写法，不混用旧名。

**来源**：WHO · Classification of Tumours: Digestive System Tumours · 版本未核实 · 未取得原件，据二次来源 · 页码待核 ｜ AJCC · Cancer Staging Manual（胃章节）· 版本未核实 · 未取得原件，据二次来源 · 页码待核

## 3 目前治疗全景概要（`landscape`）

按**病期 / 线序**分组，每组只列「指南列举过的手段类别」，不排序、不比优劣。

### 3.1 局限期（病变可以切除时）

- 内镜切除（EMR / ESD）：被列为早期病变的处理方式之一，是否适用由内镜所见与病理评估决定。
- 手术：远端胃切除、近端胃切除、全胃切除与淋巴结清扫被列出；切除范围与重建方式按手术记录原文记录。
- 围手术期化疗：术前与术后两个阶段在指南里分开表述，本台按阶段分开记录。
- 术后辅助化疗：术后病理存在特定风险因素时被列出。
- 放化疗：在部分情形下被列为可讨论选项。

### 3.2 晚期 / 转移后

- 全身化疗：以氟尿嘧啶类与铂类为基础的化疗是长期存在的选项，后续线序可包含其他化疗药。
- HER2 靶向治疗：针对 HER2 阳性情形单列。
- 免疫检查点抑制剂：按 PD-L1 CPS、MSI/dMMR 等检测结果分层列出。
- CLDN18.2 靶向治疗：针对 CLDN18.2 阳性情形列出。
- 腹腔治疗：腹膜转移情形下的腹腔灌注等做法被列出，本台单列记录、不评价疗效。
- 临床研究：指南把「参加登记良好的临床试验」列为一项正式选项。

### 3.3 贯穿全程

- 营养与进食：切除方式不同，进食调整与 B12 / 铁 / 钙等补充的医嘱也不同；本台只记医嘱原文与起止。
- 随访：胃镜与影像的复查节点按指南与医生安排执行，本台只把「约在哪天、做了没有」整理成时间线。

## 7 本项目教训

1. **「2026 版」不是版本号。** `docs/CLINICAL-DATA-2026.md` 只写了「2026 版状态未核验」，不能顺手补成 `V2.2026`；本文件全部写「版本号与更新状态未核验」。
2. **治疗全景最容易滑成推荐。** 「以氟尿嘧啶类与铂类为基础」是文献描述，一旦写成「首选」就进入第 ③ 层判断；本段只保留「指南列出过」。
3. **趋势段的登记数必须带口径。** 236 条是「2026 年首次公示 + 仅 ClinicalTrials.gov」，不写这两个限定就会被读成全量，因此连 ChinaDrugTrials 未采集一起写明。
